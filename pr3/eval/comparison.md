# Порівняння відповідей моделі

Для перевірки підготовлено 7 запитів з файлу `prompts.json`. Порівнюються два режими:

| Режим | Temperature | Top P |
| --- | ---: | ---: |
| Стриманий | 0.2 | 0.9 |
| Вільніший | 0.8 | 0.9 |

## Очікувані висновки

При `temperature=0.2` відповіді мають бути стабільнішими, коротшими і ближчими до правил з `context.md`. Такий режим краще підходить для служби підтримки, бо зменшує ризик вигаданих умов.

При `temperature=0.8` формулювання можуть бути різноманітнішими, але для запитів без відповіді в правилах модель все одно повинна повідомляти, що інформації в правилах немає. Якщо вона починає додавати умови, яких немає в `context.md`, цей режим менш придатний для задачі підтримки.

Для цієї практичної доцільно використовувати `temperature=0.2`, `top_p=0.9` і модель, вказану у `.env`.

## Як запустити фактичне порівняння

```bash
cd pr3
python eval/run_comparison.py
```

Після запуску відповіді, модель і час виконання зберігаються у `eval/results.json`.
