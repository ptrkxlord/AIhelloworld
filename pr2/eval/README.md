# Eval

1. Покладіть 5–7 зображень у `eval/images/` (JPEG/PNG), зміст яких ви знаєте наперед.
2. Для кожного заповніть `expected_objects` у `expected.json` — список класів COCO, які на ньому справді є.
3. Прогоніть кожне зображення через `/detect` (спробуйте кілька порогів confidence).
4. Порівняйте фактичний результат з очікуваним і занотуйте помилки: пропуск об'єкта, хибне спрацювання, неправильний клас, дубль.
